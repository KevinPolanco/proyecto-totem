---
name: totem-kiosk
description: >-
  Proyecto de tótem digital interactivo para trámites del gobierno de Chile.
  Pantalla táctil tipo iPad Pro 12.9. React 19 + Vite + pnpm.
  Diseño institucional: fondo blanco, azul #2F80ED para acciones principales,
  rojo #DC2626 para botón volver. Variables CSS en :root.
  Botones grandes rectangulares (min 500px, padding 2rem) para uso táctil.
  Fuente "Segoe UI", Arial, sans-serif.
  Array de trámites con id, nombre y array de pasos.
  Navegación: pantalla inicio (¿En qué te ayudamos?) → detalle con pasos numerados.
  Cada paso muestra "Paso N" en píldora azul de 120x60px + descripción.
  Pantalla inicio: 3 botones (TNE, Subsidio de agua, Registro Social de Hogares).
  Pantalla detalle: título del trámite, lista de pasos, botón volver rojo.
---
